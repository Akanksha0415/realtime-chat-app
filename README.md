# realtime-chat-app
Realtime Chat App

Welcome! This is a real-time chat application where you can send and receive messages instantly. Built with Spring Boot on the backend and React.js on the frontend, it uses WebSockets + STOMP for real-time communication.

You can chat with your friends in real-time, and messages are saved in MongoDB so nothing gets lost.
# Tech Stack

Backend: Spring Boot, Spring WebSocket, Spring Data MongoDB

Frontend: React.js, @stomp/stompjs, Axios

Database: MongoDB

Realtime Messaging: WebSocket + STOMP
# Features

Real-time chat with multiple users

Messages appear on the right for sender and on the left for receiver

Auto-scroll to the latest message

Login with just a username (no complicated signup)

Messages are stored in MongoDB
